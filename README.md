# Zig exercises on Exercism

Solution to [Zig exercises](https://exercism.org/tracks/zig/exercises) using `zig` version `0.17.0`.

- Run all unit tests in all solutions files with `zig build test --summary all`
- Run the unit tests for an individual exercise with `zig build test -Dnum=91 -Dfilter="one million" --summary all`
